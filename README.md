# 🎓 Campus Connect – Integrated Management System

Campus Connect is a **C++-based Integrated Management System** designed to help students manage academic activities and explore career opportunities through a single platform. The project combines Object-Oriented Programming (OOP) concepts with Data Structures and Algorithms (DSA) to provide an organized and efficient student management experience.

## 🚀 Features

### 📌 Opportunity Management
- Add and manage job, internship, hackathon, and quiz opportunities.
- Store opportunity details such as ID, title, type, deadline, and required skills.
- Search and organize opportunities efficiently.
- Manage opportunity records using file handling.

### 📚 Study Planner
- Create daily study tasks.
- Set subjects, topics, dates, and target study hours.
- Track completed and remaining study hours.
- Monitor task status and academic progress.

### ⚡ Priority Queue
- Organize important tasks according to priority.
- Access urgent tasks efficiently.
- Improve task management and productivity.

### 📝 Notes Manager
- Create and manage academic notes.
- Store important study information.
- Access saved notes whenever required.

### 📖 Study Resources
- Organize useful academic resources.
- Maintain learning materials for different subjects.

### 💡 Study Tips
- Access useful study tips.
- Improve study habits and learning efficiency.

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Concepts:** Object-Oriented Programming (OOP)
- **Data Structures:** Vectors, Hash Tables, Priority Queues, Linked Lists
- **Algorithms:** Sorting and Searching
- **File Handling:** Text File Storage
- **Libraries:** iostream, fstream, sstream, string, vector, algorithm, iomanip, cstdlib

## 🧠 DSA Implementation

| Data Structure / Algorithm | Application |
|---|---|
| Hash Tables | Efficient searching of students and opportunities |
| Priority Queue | Managing urgent study tasks |
| Vectors | Storing and managing records |
| Sorting Algorithms | Organizing opportunities and records |
| Binary Search | Searching sorted records |
| File Handling | Persistent storage of application data |

## ⚙️ Installation & Execution

### 1. Clone the Repository

```bash
git clone https://github.com/vishesh-juyal0/Campus-connect-.git
```

### 2. Navigate to the Project Directory

```bash
cd Campus-connect-
```

### 3. Compile the Program

Using GCC:

```bash
g++ main.cpp -o campus_connect
```

### 4. Run the Application

On Windows:

```bash
campus_connect.exe
```

On Linux/macOS:

```bash
./campus_connect
```
