CampusConnect

CampusConnect is a C++17-based Integrated Student Management and Productivity System developed as a Problem-Based Learning (PBL) project. It is designed to provide students with a centralized platform to manage academic tasks, study schedules, notes, learning resources, and career opportunities.

The project focuses on combining practical student-oriented features with Object-Oriented Programming (OOP) and Data Structures & Algorithms. It includes modules for study planning and productivity, opportunity management, notes and resources, and student-related information.

Key Features

- Study planner with task priorities and deadlines
- Productivity and study-hour tracking
- Notes and learning-resource management
- Internship, hackathon, quiz, and job opportunity management
- Task organization using efficient data structures
- Modular and scalable C++17 architecture

Technical Concepts

- C++17
- Object-Oriented Programming
- Priority Queue
- Queue
- Linked List
- Sorting Algorithms
- Modular Software Design

CampusConnect is currently under development, with new features and improvements being added as the project progresses.
